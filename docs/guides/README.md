# 사용 가이드

[프로젝트 소개](../../README.md) · [개발 진행 현황](../DEVELOPMENT_STATUS.md)

가구다방을 **처음 쓰는 분**을 위한 안내서입니다. 개발 지식이 없어도 읽을 수 있게 썼고, 실제 화면에 **빨간 번호**를 붙여 "어디를 누르면 무엇이 되는지" 보여 줍니다. 컴퓨터 화면과 휴대폰 화면을 모두 담았습니다.

| 나는 누구인가요? | 읽을 가이드 | 인쇄용 PDF |
| --- | --- | --- |
| **가구를 맡기려는 고객** (회원이든 아니든) | [고객 이용 가이드](고객_이용_가이드.md) | [PDF](고객_이용_가이드.pdf) |
| **접수를 받아 처리하는 운영자** | [관리자 이용 가이드](관리자_이용_가이드.md) | [PDF](관리자_이용_가이드.pdf) |

## 두 가이드에서 다루는 내용

**고객 이용 가이드**

1. 첫 화면 보기 → 2. 가구 접수하기(신청자·수거 장소·일정, 가구와 사진, 동의와 접수) → 3. 접수 완료와 접수번호
4. 진행 조회와 취소 → 5. 진행 상태 읽는 법 → 6. 회원가입과 로그인 → 7. 마이페이지
8. 휴대폰에서 쓰기 → 9. 자주 묻는 질문

**관리자 이용 가이드**

1. 로그인 → 2. 접수 목록 보기 → 3. 접수 열어보기(운영 메모) → 4. 가구별로 처리하기(처리 구분, 상태, 마감일, 반출 일정, 안내문)
5. 상태 바꾸기와 확인 → 6. 문자 문구 → 7. 사진 크게 보기와 변경 이력 → 8. 일정 보기(직접 추가 포함) → 9. 통계 보기
10. 설정 → 11. 휴대폰에서 쓰기 → 12. 용어 풀이 → 자주 겪는 일

## 알아두세요

- 화면 그림 속 **이름·주소·전화번호는 설명용 예시**입니다. 버튼과 칸의 위치·이름은 실제 화면과 같습니다.
- 고객 화면은 서비스 주소 그대로, 관리자 화면은 주소 끝에 `/admin`을 붙여 엽니다.
- 그림은 2026-11-27 기준 화면입니다.

## 가이드를 고치거나 다시 만들 때 (관리자용)

화면이 바뀌면 그림과 PDF를 다시 만들 수 있습니다.

| 하는 일 | 방법 |
| --- | --- |
| 글 고치기 | 이 폴더의 `.md` 파일을 고칩니다. 그림은 `../assets/guide/`에 있습니다. |
| 화면 그림 다시 찍기 | `npm run build` 뒤에 `node scripts/guide/capture.mjs`. 실제 앱을 임시 데이터로 띄워 접수부터 처리까지 직접 눌러 보면서 찍고, 한 단계라도 기대와 다르면 실패로 알립니다. (`playwright-core`가 없으면 먼저 `npm i --no-save playwright-core`, Edge 필요) |
| PDF 다시 만들기 | `node scripts/guide/build-pdf.mjs` (인터넷 연결과 Edge 필요) |

> 글에서 설명하는 **번호**는 그림의 번호와 같아야 합니다. 번호를 바꾸면 `scripts/guide/capture.mjs`의 표시 목록과 글을 함께 고치세요.
