- **작성 목적**: `가구팔고비움 (furni-resale)` MVP 설계를 위한 국내 주요 유사 플랫폼(7개사)의 **화면 페이지 구성, 핵심 강점, 특이 기능, 최소 기본 기능, UI/UX 디자인 스타일** 심층 분석
- **조사 범위**: 국내 운영 플랫폼 한정 (대중 수거·폐기·매입 결합형 / 비교견적 매칭형 / 원스톱 정리·처분형 / 가구 물류·위탁 리세일형 / 하이엔드 위탁판매형)

## 2. 플랫폼별 상세 분석

---

### ① 빼기 (Bbaegi) — `(주)같다`
> **분류**: 대형폐기물 모바일 간편 배출 · 방문 수거(`내려드림`) · 중고매입 연계 플랫폼

- **화면·페이지 구성 (IA & Flow)**
  1. **홈 대시보드**: 상단 동네(읍·면·동) 위치 설정 + 핵심 서비스 4대 퀵 아이콘(`직접버림` / `내려드림` / `중고매입` / `철거·원복`) + 지자체 협약 안내 배너
  2. **품목·사진 등록 화면**: 카메라 즉시 촬영 또는 앨범 업로드 → AI 사물인식으로 가구 품목·규격 자동 추천 → 스크래치·작동 여부 체크박스 선택
  3. **일정·장소 입력 화면**: 배출/수거 주소, 엘리베이터 유무, 희망 수거 날짜·시간대 캘린더 지정
  4. **중고매입 견적 / 전환 화면**: 파트너 매입 입찰가 리스트 확인 → 매입 불가 시 하단 고정 버튼으로 `내려드림(방문수거)` 또는 `직접버림`으로 즉시 전환
  5. **하단 GNB**: `홈` / `중고거래` / `내 주변` / `알림` / `마이페이지(배출·수거 진행상태)`
- **핵심 강점**
  - 지자체 공식 제휴 기반으로 폐기물 스티커 없이 모바일로 끝내는 압도적 편의성
  - "팔 수 있으면 팔고, 안 팔리면 바로 버린다"는 **판매→처분 원스톱 연결성**이 가장 뛰어남
- **특이한 기능 (Signature)**
  - **AI 사물인식 사진 자동 분류**: 가구 사진을 찍으면 품목(장롱, 소파 등)과 대형폐기물 수수료 규격을 자동 매칭
  - **`내려드림` 방문 반출**: 혼자 옮길 수 없는 무거운 가구를 파트너 기사가 집 안부터 수거
  - **크로스셀링 전환 CTA**: 중고 매입이 거절되어도 재입력 없이 폐기·방문수거로 바로 넘어가는 플로우
- **최소 기본 기능 (Baseline)**
  - 지역(주소) 설정, 가구 사진 촬영·첨부, 품목·상태 체크, 희망 수거일 선택, 진행 상태 알림
- **UI/UX 및 디자인 스타일**
  - **컬러**: 친환경·자원순환을 상징하는 **민트 그린(`#00C781` 계열) + 화이트 배경**
  - **스타일**: 모바일 앱 네이티브 감성의 큼직한 둥근 카드(Rounded Card), 직관적인 일러스트 아이콘, '스티커 비용 절약' 등 혜택을 강조하는 컬러 배지 활용

### ② 피커스 (RE:PICKUS)
> **분류**: 전국 재활용센터·전문 파트너 연결 중고가전·가구 매입·수거·철거 비교견적 플랫폼

- **화면·페이지 구성 (IA & Flow)**
  1. **메인 홈**: 핵심 슬로건 히어로 배너 + `견적 신청하기` / `AI 시세조회` 메인 CTA + 서비스 목적별 진입 카드(`한 개 팔기` / `다량 팔기` / `철거·원복` / `기업 견적`)
  2. **견적 신청 페이지 (스텝형 폼)**:
     - Step 1: 단일 품목 vs 다량 품목(이사·정리) 유형 선택
     - Step 2: 카테고리(가구/가전), 제조사·브랜드, 연식, 상세 상태 입력
     - Step 3: 정면 사진 + 흠집·특이사항 부위 다중 사진 업로드
     - Step 4: 수거 지역(주소), 층수·엘리베이터 유무, **희망 수거일** 입력 후 접수
  3. **마이페이지 (견적·입찰 현황)**: 지역 제휴 파트너들의 매입가/수거비 입찰 내역 비교, 업체 후기 확인 및 최종 업체 선택
  4. **피커스 샵 (중고 구매)**: 파트너가 검수·클리닝한 중고 가구·가전 판매 마켓
- **핵심 강점**
  - 이사 전 **다량의 가구를 한 번에 정리**할 때 여러 재활용센터의 매입 가능 여부와 수거 조건을 한 번의 등록으로 비교 가능
  - 매입 가능한 가구와 유료 수거(처분) 대상을 한 견적 안에서 복합 처리 가능
- **특이한 기능 (Signature)**
  - **단일 팔기 vs 다량 팔기 분리 진입**: 이사 고객이 여러 가구를 한꺼번에 올리기 편하도록 신청 동선을 이원화
  - **카메라 아이콘 AI 시세조회**: 본격 신청 전 사진으로 대략적인 중고 매입 가능 시세를 사전 조회
  - **역경매 파트너 비교 입찰 UI**: 파트너별 제시 금액과 평점을 비교해 선택하는 구조
- **최소 기본 기능 (Baseline)**
  - 다품목 정보·연식·상태 입력, 다각도 사진 업로드, 주소·엘리베이터 유무·희망 수거일 수집, 견적 상태 관리
- **UI/UX 및 디자인 스타일**
  - **컬러**: 신뢰감과 재활용을 결합한 **에메랄드 그린·블루 톤 + 라이트 그레이 섹션 구분**
  - **스타일**: PC와 모바일 웹 모두 대응하는 실용적인 반응형 포털 레이아웃, 단계 진행률(Progress Bar)이 표시되는 명확한 입력 폼 구조

### ③ 우아한정리 — `(주)우아한정리`
> **분류**: 이사·이민·집 정리 시 대형 가구 및 생활폐기물 비대면 견적·원스톱 방문 수거 대행

- **화면·페이지 구성 (IA & Flow)**
  1. **전환형 랜딩 홈 (`/`)**: 강렬한 슬로건 히어로 + 즉시 `무료 견적 신청` / `예상 비용 계산기` 진입 CTA + 서비스 영역 아이콘 그리드 + 전후(Before/After) 작업 포트폴리오 + 실제 고객 리뷰 + 언론 보도·보증 마크
  2. **예상 비용 계산기 페이지**: 평수, 물량(트럭 단위/품목 수), 작업 환경 선택 시 예상 비용 범위 즉시 시뮬레이션
  3. **간편 비대면 견적 신청 폼**: 성함, 연락처, 작업 지역(주소), 엘리베이터/층수 정보, **희망 작업(반출)일**, 현장·가구 사진 첨부, 요청 메모 입력 (비회원 즉시 신청)
  4. **포트폴리오 & 후기 게시판**: 실제 가구 반출·정리 전후 사진 사례집
- **핵심 강점**
  - **회원가입 없는 초간편 랜딩→폼 전환 구조**로, 우리 `가구팔고비움`의 고객 화면 구조(소개·절차 안내 → 비회원 즉시 신청)와 전환 동선이 가장 흡사함
  - 방문 견적 부담 없이 사진 전송만으로 비대면 견적 및 일정 확정이 가능
- **특이한 기능 (Signature)**
  - **인터랙티브 예상 비용 계산기**: 조건 몇 개만 누르면 대략적인 처리 견적 범위를 미리 보여줘 신청 전환율 극대화
  - **비밀보호·안심접수 배지**: 폼 주변에 개인정보·프라이버시 보호 안내를 배치해 신청 심리 장벽 완화
  - **Before & After 시각 사례**: 깔끔하게 비워진 방 사진을 전면에 배치해 '비움'의 결과를 직관적으로 전달
- **최소 기본 기능 (Baseline)**
  - 서비스 소개·절차 랜딩, 비회원 원페이지 신청 폼(연락처·주소·희망일·사진 첨부·메모), 운영자 유선/문자 상담 연계
- **UI/UX 및 디자인 스타일**
  - **컬러**: 전문성과 청결·신뢰를 주는 **네이비·로열 블루(`#1E40AF` 계열) + 깔끔한 화이트 바탕**
  - **스타일**: 군더더기 없는 플랫 & 클린 카드형 레이아웃, 굵고 가독성 높은 고딕 타이포그래피, 모바일 엄지 영역에 맞춘 큼직한 하단/중앙 CTA 버튼

### ④ 현대리바트 가구숨터 *(구 오구가구)* — `(주)현대리바트`
> **분류**: 대기업 전문 설치기사 해체·수거·이전설치 물류 결합형 중고가구 거래·리퍼·케어 플랫폼

- **화면·페이지 구성 (IA & Flow)**
  1. **통합 홈 화면**: 4대 핵심 솔루션 탭(`중고가구 거래` / `리퍼마켓` / `이전설치 예약` / `소파·매트리스 케어`) + 기획전 배너
  2. **중고가구 등록·판매 화면**: 가구 사진·동영상 업로드, 브랜드·품목·크기·상태 입력, 희망 판매가 설정, 해체·설치 필요 여부 체크
  3. **이전설치·반출 예약 화면**: 출발지·도착지 주소 및 층수(사다리차/엘리베이터 여부), 가구 종류(침대·붙박이장·소파 등), **희망 방문 일정 지정**
  4. **상품 상세 및 안전결제 화면**: 가구 상태 등급, 예상 전문 배송·설치비 안내, 에스크로 결제
- **핵심 강점**
  - 중고가구 거래 최대 난제인 **"누가 무거운 가구를 분해해서 내리고 옮기느냐"**를 전문 설치기사 인프라로 완벽히 해결

## 3. 국내 플랫폼 분석 종합: `가구팔고비움 (furni-resale)` MVP 설계 반영 전략

### A. 7개 국내 플랫폼에서 공통 확인된 '최소 기본 기능 (MVP Baseline)'
1. **직관적인 3~4단계 이용 절차 시각화 섹션** (`우아한정리`, `풀티` 공통) — 처음 방문한 고객이 "사진만 올리면 알아서 팔고 치워주는구나"를 5초 안에 이해
2. **비회원 모바일 퍼스트 신청 폼** (`우아한정리`, `빼기` 공통) — 로그인 장벽 없이 **연락처 + 주소(층수·엘리베이터) + 희망일(이사일·반출일) + 가구 다품목 사진·상태**를 한 번에 제출
3. **촬영 가이드가 있는 다중 사진 첨부 UI** (`풀티`, `피커스` 공통) — "전체 사진과 흠집 부위를 함께 올려주세요" 한 줄 가이드만으로도 운영자 검토 정확도 대폭 향상
4. **판매 가능 품목과 단순 처분 품목의 통합 수용** (`빼기`, `피커스` 공통) — 상태 등급에 `하(처분 희망)`까지 두어 이사 전 가구를 한 번에 맡길 수 있게 구성
5. **운영자 중심의 품목별 상태·일정 백오피스** — 접수 건 내 개별 가구마다 **상태(접수대기 → 진행중 → 반출예정 → 처리완료), 판매 마감일, 반출 일정**을 관리하고 원터치로 고객에게 연락

### B. `가구팔고비움` 추천 UI·디자인 스타일 조합
- **레이아웃 레퍼런스**: **`우아한정리`의 높은 신청 전환형 랜딩 구조** + **`풀티`의 깔끔하고 정돈된 원페이지 카드형 신청 폼**
- **컬러 & 톤앤매너 레퍼런스**: **`딜아트`·`가구숨터`의 웜 아이보리/화이트 배경 + 딥 에메랄드 그린(신뢰·자원순환) & 우드 차콜 포인트** — 폐기물 업체처럼 딱딱하지 않으면서도 명품 전용 플랫폼처럼 진입장벽이 높지 않은, **누구나 부담 없이 신청할 수 있는 깔끔한 주거·리빙 톤**
